webOS ATL 32-bit beta (for testers)

A test build of webOS ATL (Android apps on rooted LG TVs) that uses only the 32-bit ATL runtime. It has the same app id as webOS ATL, so it replaces an existing webOS ATL install. Your Android apps and their data stay; the 64-bit runtime is removed. Needs root (Homebrew Channel).

New in 0.2.3

  • Faster app starts: only apps with a real WebView load WebKit (NewPipe and SmartTube open in about 6 s, were 9-10 s); zstd runtime image.
  • Hardware video picture in the app's player area, with the app's controls visible and the video dimmed behind them.
  • Android TV apps get arrow-key mode by default, so the remote works in player controls.
  • Android badge on app icons and a launch splash.
  • LG background preloads are paused while an Android app is in front.
  • New runtime 0.2.3 (about 225 MB download after the update).

New in 0.2.1

  • USB storage (off by default): Settings → Storage moves the Android runtime and the apps' data to a USB drive (FAT32, exFAT or NTFS; the data goes into an ext4 image file on it) and back. Android apps start only while the drive is plugged in.
  • SmartTube: install the armeabi-v7a (or universal) APK.
  • The hardware video decoder is always released when an app closes; app caches in RAM are deleted when the app stops.
  • Updates from 0.1.x/0.2.0 now load the new programs (the old service is restarted by the app).
  • Hardware video decoding uses LG's Starfish pipeline (H.264, HEVC, VP9); video decoded in software is offered at most 1080p, so apps don't pick 4K they can't play.
  • New runtime 0.2.1 (about 260 MB download after the update).

What's being tested in 0.2.0

  • 32-bit only: every app runs on the 32-bit runtime (about 260 MB download). Apps that ship only 64-bit (arm64-v8a) libraries are refused, with a message on the TV and in the app's log.
  • Tested in GitHub runner twins of an LG 43UR7500 (webOS TV Lite 10.3.1): 597 of 1043 apps worked. Not tested on a real TV yet. LG GL and hardware video decoding are untested with this runtime.

Rollback

Reinstall webOS ATL 0.1.1 (org.webosatl.manager) from github.com/sarahahzub/WebOS-ATL/releases.

Your TV model, webOS version, which apps start and which don't, and the app log from webOS ATL (Android apps → the app → App log): github.com/sarahahzub/WebOS-ATL/issues (mention "32-bit beta 0.2.1").
