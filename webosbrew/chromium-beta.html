Chromium Beta (for testers)

A test build of WebOS Chromium. It installs next to the normal Chromium app with its own icon, settings and bookmarks, so it can't break your normal install. Remove it any time.

What's being tested in 0.0.57

  • webOS 4: the separate webOS 4 test app is merged into Chromium Beta; one build for webOS 4.4 and newer.
  • New: WebRTC H.264 (video calls and casting pages).
  • New: WebGL works; likely fix for the Magic Remote pointer on older TVs (clicks and scrolling did nothing).
  • New: Enter works on the first press; Play/Pause buttons control videos; Google uses its desktop version ("Web" filter works); logs of the previous session survive a restart (<app>/data/lastlog.prev/).
  • New: a remote and pointer log (cn-input: lines in browser.log) for TVs where the pointer, scrolling or keys don't work; WebGPU off; built for glibc 2.24 with its own NSS.
  • Older TVs: this build is meant to run on webOS 4.4 (2018-2019) and newer; the normal app needs webOS 9.
  • Fixed: the crash right after the splash screen on TVs whose graphics driver is older (e.g. LG C1, webOS 6). Those TVs draw pages without the GPU by default; GPU drawing can be tried with gpu=on.
  • New: GPU drawing on older Mali TVs (webOS 5/6) when the TV's driver passes the start-up check.
  • A GPU report in /tmp/org.nativechromium.browser.beta/media.log on TVs where the GPU is off.
  • Hardware video, GPU drawing and the remote on those older models.

Please report

Your TV model, webOS version, and whether it starts, plays YouTube smoothly and works with the remote: github.com/sarahahzub/WebOS-Chromium (TV compatibility report, mention "Beta 0.0.57").
